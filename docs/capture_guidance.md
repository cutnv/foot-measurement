以下为当前行为，优先于下文第一轮记录：

- 网页相机需要有效传感器数据，俯拍 0–5°、侧拍 30–35° 连续稳定 500 ms 才允许拍照；读数超范围立即锁定，距最后有效样本超过 350 ms 也会锁定。点击快门时再次检查，不能只依赖按钮样式。
- 无权限、无传感器和系统相机/相册保留兼容入口，明确标注“未经传感器验证角度”。传感器参考不证明相机平移或内外侧正确。
- 所有入口选图后调用 `/api/photo-quality`。无效、严重模糊、分辨率不足、严重偏暗照片阻止测量；纸边不确定、轮廓分割不一致和轻度风险给出单张重拍建议，允许进入最终联合几何检查，不假装单张已验证角度。横竖方向/比例不同阻止提交。
- 质检连接失败时保留照片并提供重新检查按钮。替换/删除照片会中止旧检查，旧响应不能覆盖新照片。

## 行为

- 先选择左右脚。以脚尖朝前、脚跟朝自己为基准，画面左侧对应右脚内侧/左脚外侧，画面右侧相反。
- 点击拍照先显示位置示意，再分别开启后置相机、角度参考。拍照输出原始视频帧 JPEG，不包含引导线，不裁剪。
- 手机后置相机相对重力竖直向下方向的倾角为 acos(cos(beta)*cos(gamma))。屏幕朝下、缺失或非有限读数不可用。参考区间：俯拍 0–5°，侧拍 30–35°。
- 该读数不能验证相机横向平移、内外侧位置、脚是否居中或地面是否水平。只有镜头对准脚中心等条件成立时才可作位置角的近似参考；后端几何检查仍保留。
- HTTPS、浏览器权限和硬件支持决定能否使用网页相机和传感器。失败时保留系统相机与文件上传，不生成虚假角度。
- 关闭、后台切换和离开页面会停止相机；关闭后才完成的权限请求也会释放视频轨道。

## 验收

1. 左右脚分别检查两侧名称与位置图；三张保持竖拍、同一镜头、不变焦。
2. 分别允许/拒绝相机和传感器，确认提示和备用入口；无传感器时不应显示角度达标。
3. 侧拍倾角变化经过 30–35°，观察提示变化；仅原地倾斜仍不能证明位置正确。
4. 拍摄后检查预览无虚线；关闭/切换后台后相机停止；重复拍照可替换。
5. 上传完整三视图测量，检查原尺寸/置信度/重拍逻辑。真人实拍及 iOS/Android 多浏览器验收仍需进行。

开发检查：node web/test_capture_guide.cjs；在 web 目录运行 python -m unittest test_multiview_precheck test_multiview_robustness。

浏览器接口依据：https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia 与 https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent/requestPermission_static 。
